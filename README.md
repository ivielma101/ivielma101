I'm Irwing, based in New York. Most of what I work on is forecasting and logistics for places that are hard to reach, mostly Alaska.

What I've been working on:

- [NomeDustPrediction](https://github.com/ivielma101/NomeDustPrediction): forecasting road dust (PM10) in Nome, Alaska. It's a LightGBM model plus a frozen-ground rule, since dust can't kick up when the ground is frozen. Has a map of risk by road.
- [AlaskaResourceAllocate](https://github.com/ivielma101/AlaskaResourceAllocate): a map-based simulator for deciding where to stage supplies after an incident in the Arctic.
- [EmergencyFoodAllocation](https://github.com/ivielma101/EmergencyFoodAllocation): an integer program that splits up emergency food to keep people going as many days as possible.
- [Autonomous Navigation with LiDAR](https://github.com/rneddojr/Autonomous-Navigation-using-LiDAR-and-Agile-X-Robotics): group project getting an AgileX robot to drive itself.

Mostly Python, some TypeScript and C++.
